# **哨戒機およびSDR搭載Gサイズソノブイを用いたHF帯地表波Rx-TDOA代替PNTシステム提案書**

# **1. システム概要**

本提案システムは、GPS拒否（GPS-Denied）環境下において、母機である哨戒機の慣性航法装置（INS）の累積誤差（ドリフト）を確実に抑え込み、システム全域でのナノ秒単位の時刻同期と高精度代替PNT（Position, Navigation, and Timing）を実現するソリューションです。GPS機能が封殺・妨害された過酷な電磁波環境下であっても、自律航法性能を正確に維持し、哨戒・追尾などの戦略的ミッションを中断することなく継続担保することを主目的としています。

標準的なGサイズソノブイの筐体に小型SDR（Software Defined Radio）および処理ユニットを搭載し、哨戒機から海域へ投下・展開します。既知の位置にある複数の友軍HF送信局（アンカーノード）から発射されるHF帯（3〜30MHz）地表波（Surface Wave）を受信・処理（Rx-TDOA）することで、広大なベースライン（基線長）を形成し、周辺海域において極めて高い精度（良好なGDOP）で視界外（OTH）領域での絶対位置特定と同期補正を可能とします。

## **ゼロ・モディフィケーション設計と柔軟な運用**

既存の哨戒機に設置されているVHF/UHF帯ソノブイ受信インフラ（データリンク受信機および処理システム）をそのまま活用する「ゼロ・モディフィケーション設計」を採用しています。ソノブイ内部でHF帯信号を受信・一次処理し、既存のソノブイ通信フォーマット（VHF/UHF）に圧縮・変換して哨戒機へ伝送するため、機体側のハードウェア改修を一切必要とせず、即座に導入・運用が可能です。

# **2. コア技術要素**

本システムを実現する中核技術は、友軍HF地表波を利用したINSドリフトのバウンディング、高度なナノ秒レベルの時刻同期、およびデータ圧縮技術にあります。広範に配置された複数の友軍HF局からの代替PNT用アンカー信号として「パイロットトーン付きOFDM（帯域幅3kHz〜6kHz、NATO STANAG 4539拡張等）」を採用し、広大な基線長による良好なGDOPを活かしたパイロット信号の搬送波位相（Carrier Phase）ロックにより、高精度な時刻同期とINSバウンディングを実現します。

## **HF帯地表波Rx-TDOAによるINSドリフト補正**

既知の位置に配置された複数の友軍HF局からの地表波信号を、各ソノブイおよび哨戒機の受信機で同時受信します。未知の発信源の位置を推定する一般的なTDOAとは異なり、本方式は「位置が既知である複数の送信局からの信号を受信機側で受けて到達時間差（Rx-TDOA）を計算し、受信者自らの絶対位置を導き出す」という逆TDOA（Reverse TDOA / Direct Passive Localization）の原理に基づいています。ソノブイ自体は高価なINSを搭載せず海面を漂流する基準点（アンカー）として機能し、自ら電波を発することなく無追跡（パッシブ）のまま、GPSに依存せず母機（哨戒機）のINS固有の位置誤差（ドリフト）を効果的に抑え込み（バウンディング）、高精度な位置情報を維持します。

  - **ナノ秒精度時刻同期:** 地表波の安定した伝搬特性を利用し、ネットワーク内のすべてのソノブイと哨戒機間でナノ秒レベルの分散時刻同期を達成・維持します。
  - **データ圧縮とIQ抽出:** SDR/FPGA処理により必要なIQデータと特徴量（到達時間差）のみを抽出・圧縮し、既存のVHF/UHF通信リンクでリアルタイムに伝送します。

## **EKF（拡張カルマンフィルタ）による誤差楕円の収束**

地表波は海洋の海水塩分濃度、波浪状態（海面粗度）、および電磁気的特性の影響を受けて伝搬速度や減衰率が複雑に変化します。

  - **動的伝搬モデルの統合:** 沿岸・外洋の海洋環境データを組み込んだ伝搬モデルをEKFのシステム行列に統合します。
  - **誤差楕円の高速収束:** 複数ブイからのTDOA/FDOA（周波数差）データおよび時系列の移動ベクトルを複合的に処理することで、伝搬遅延誤差をリアルタイムに推定・補正し、目標位置の誤差楕円（CEP）を短時間で大幅に収束させます。

## **超分解能アルゴリズム（MUSIC / ESPRIT）**

ブイに配置されたマルチエレメント・アンテナまたは複数ブイの連携アレイを用いて、超分解能方位推定量アルゴリズム（MUSIC, ESPRIT）を適用します。これにより、従来のビームフォーミングの限界（レイリー限界）を超越した角分解能を達成し、接近した複数目標の分離・識別および高精度なAOA推定を実現します。

# **3. GサイズRFソノブイ群による代替PNTグリッドの局所展開**

本システムでは、対潜探知（追尾）を担当する標準的な対潜ソノブイと、位置補正（代替PNT）を専門に担う「GサイズRFソノブイ」を完全に分離した専用ブイ（独立ペイロード）として扱います。1つのブイで機能を兼用するのではなく、哨戒機が通常の対潜探知・追尾ミッションを実行する傍らで、自機の位置補正専用として「5〜9本程度」のGサイズRFソノブイを特定の海域へ局所的に投下・展開します。これにより、対潜任務を完全に維持したまま、並行して高精度な代替PNTグリッドを形成・支援するアーキテクチャを実現します。

  - **専用RFソノブイによる局所PNTグリッド形成:** 位置補正専用のGサイズRFソノブイ（5〜9本程度）を局所展開し、各ブイがHF地表波を受信することで、対潜用ブイ群の配置に依存せず独立した高精度な代替PNT基準（ローカルDGPS網）を即座に構築します。
  - **オンデマンド・キャリブレーションによるINS補正:** 哨戒機が展開したRFソノブイグリッドの上空を周回・飛行することで、ナノ秒同期された位置データを直接受信し、自機INS（慣性航法装置）の累積誤差（ドリフト）を短時間で確実かつ強力に抑え込み（バウンディング）ます。

# **4. システムアーキテクチャとデータフロー**

本システムは、エッジ（Gサイズソノブイ）とクラウド/親機（哨戒機）間における非対称な役割分担により、既存インフラを最大限活用した効率的な処理系を構築します。

  - **エッジ側（Gサイズソノブイ）の処理:** 内部の小型SDRおよびFPGAを活用し、帯域幅3kHz〜6kHzのパイロットトーン付きOFDM（NATO STANAG 4539拡張等）アンカー信号に対する帯域制限および超高倍率のダウンサンプリングと特徴量抽出を直接実行します。パイロット信号による搬送波位相ロックを活用して特徴量を高度に圧縮・精製することで、データリンクの120kbps帯域制限を完全にクリアしつつ高精度な同期を実現します。
  - **データ伝送（既存通信リンクの活用）:** 既存のVHFアップリンクにおける物理的な通信帯域は「120kbps」という厳格な制約が存在するため、一次処理・圧縮された軽量データおよび到達時刻（TDOA）等の特徴量情報のみを伝送します。哨戒機からの制御 command や同期信号はUHFダウンリンク経由で各ソノブイへ届き、機体側のハードウェア改修を不要とする「ゼロ・モディフィケーション」を実現します。
  - **クラウド/親機側（哨戒機）の処理:** 複数ブイから収集したデータを統合し、高度な相関処理および拡張カルマンフィルタ（EKF）を適用します。海洋環境データを反映した伝搬モデルと組み合わせることで、誤差楕円の高速収束と高精度な目標位置特定（ジオロケーション）を行います。

# **5. 予想される測位精度とRNP要件への適合**

地表波の伝搬特性およびマルチブイ・ジオメトリ最適化により、従来のHF帯測位を大きく上回る精度を実現します。

| 項目 | パラメータ / 性能値 | 備考 |
| :-: | :-: | :-: |
| 探知距離 | 100 km 〜 300 km+ | 地表波伝搬による視界外（OTH）探知 |
| 位置精度 (CEP) | 1.0 km 〜 2.5 km (100km視界時) | EKF収束後の3σ精度 |
| RNP要件適合 | RNP 1.0 / RNP 2.0 基準 | 警戒海域における哨戒・誘導支援に適合 |
| データ更新レート | 5秒 〜 10秒 | EKFによる継続トラッキング時 |

超分解能AOAとTDOAをハイブリッド処理することにより、GPS拒否環境下においても戦術データリンク（Link 16等）経由で誘導・警戒情報を共有するのに十分なRNP（Required Navigation Performance）精度レベルに適合します。

## **沿岸基線距離 vs. 測位誤差 (CEP) 航法性能評価**

友軍HF送信局からの基線距離に応じた伝搬減衰およびGDOPの変化を考慮し、本システムが提供する測位精度と適合する航法性能（RNP）を以下の3段階で評価・分類します。

  - **第1段階（沿岸から約400km以内）:** 高SNR環境かつ良好なGDOPが維持されるエリアです。パイロット信号の搬送波位相（Carrier Phase）ロックが完全に機能し、測位誤差（CEP）は1.85km（1.0 NM）以内を達成します。これにより極めて高度な戦術目標追尾およびRNP-1要件に完全適合します。
  - **第2段階（約400km〜1,000km）:** 距離増大に伴い海面散乱や伝搬遅延の変動、位相スリップ（Phase Slip）が発生し始める領域です。搬送波位相ロックの更新頻度が低下する場合でも、OFDMエンベロープ相関とEKF（拡張カルマンフィルタ）を中心とした時系列フィルタリングにより、測位誤差（CEP）を3.7km（2.0 NM）以内に維持し、RNP-2要件に適合する航法性能を継続提供します。
  - **第3段階（約1,000km〜2,000km以上）:** 視界外（OTH）超遠距離領域であり、地表波の減衰が大きくなる限界領域です。TDOA特徴量抽出を中心とした処理に移行しますが、測位誤差（CEP）を18.5km（10.0 NM）以内に抑え込みます。広域外洋における完全GPSロスト時においても機体INS（慣性航法装置）の無制限な累積誤差発散を防ぎ、長時間の自律飛行と帰還を支えるRNP-10適合の「究極のセーフティネット」として機能します。

# **6. 今後の課題**

本システムの即応配備および実用化に向け、以下の要素技術・法制度上の課題に取り組む必要があります。

  - **ソフトウェアによる安全性証明とセキュリティ保証:**
      - ソノブイ内および機上処理ユニットで動作するSDRソフトウェアの信頼性確保（DO-178C等の航空ソフトウェア認証プロセスに準拠した検証）。
      - データリンク経由での防諜・妨害対策（耐ジャミング性強化および暗号化通信の確立）。
  - **過酷な海洋環境におけるアンテナ展開機構:**
      - Gサイズ（直径約12.4cm、長さ約91cm）という制限された筐体から、HF帯（波長10m〜100m）を受信するための高効率エレメントアンテナを確実に海上に展張する小型機構の開発。
  - **リアルタイム伝搬環境学習（AI/MLの適用）:**
      - リアルタイムの波浪状況や気象データからHF伝搬減衰・相関不規則性を自己学習・補正するエッジAIアルゴリズムの実装。

# **【開発引継書】GPS拒否環境下における哨戒機用 代替PNT・ソノブイネットワーク位置補正シミュレータ**

本ドキュメントは、Claude（AIアシスタント）および新規開発チームへ本プロジェクトの開発コンテキスト、技術アーキテクチャ、および実装要件を円滑に引き継ぐための詳細仕様書です。

# **1. プロジェクトの目的と概要**

本プロジェクトは、GPSスプーフィン/ジャミング等の**GPS拒否環境（GPS-Denied Environment）**において、**Gサイズソノブイ（最大200本）**および哨戒機（MPA）が**友軍HF地表波（Ground Wave）信号を活用して航空機自身の高精度位置補正（INSバウンディング）と代替PNT（Positioning, Navigation, and Timing）機能を実現するシミュレーション環境**の構築を目的としています。本シミュレータが検証すべき最重要・最終目的は、完全なGPSロスト環境下においても、哨戒機が正確な自機位置・時刻同期を維持することで、対潜哨戒・展開ミッションを完遂し、確実な生還を担保することにあります。

  - **HF地表波（High Frequency Ground Wave）を活用した代替PNT**  
    GPS信号が利用できない状況下で、見通し外まで到達する友軍HF送信局の地表波を利用し、高精度な相対/絶対位置・時刻同期（PNT）情報を提供します。
  - **Gサイズソノブイ規格の採用とローカルDGPS網の構築**  
    標準的なGサイズ（直径約124mm、全長約368mm）の標準ソノブイ筐体フォーマットにセンサ・RF伝送系・電源を収容します。最大200本のソノブイ群を展開・分散配置することで「空間ダイバーシティ効果による局所フェージングの平均化」を実現し、自機のINS（慣性航法装置）誤差を正確に抑制するための強固な海面ローカルDGPS網を構築します。
  - **ゼロ・モディフィケーション（Zero-Modification）構想**  
    既存の市販ハードウェアや標準ファームウェアインターフェースに大幅な変更を加えず、ソフトウェア・プロキシ（LiteLLM等）およびエッジでの補正アルゴリズム処理によってシステム要件を満たす設計を採用します。
  - **TDOA / EKF による INS バウンディング（位置誤差抑制）**  
    HF地表波により絶対座標が確定されたソノブイネットワークとの到達時間差（TDOA）および位相特性を基準として拡張カルマンフィルタ（EKF）を駆動し、母機である哨戒機の慣性航法装置（INS）の累積ドリフト誤差を抑制（バウンディング）します。（ソノブイ自身は高価なINSを搭載せず海面を漂流するため、主対象は母機のみとなります。）

# **2. 要求仕様とアーキテクチャ**

システム全体の可用性と柔軟性を担保するため、エッジノードとクラウド基盤をLiteLLM ProxyおよびDockerコンテナ群によって結合するマイクロサービスアーキテクチャを採用します。

## **全体コンテナ構成**

  - **LiteLLM Proxy + Docker**  
    マルチモデルLLM呼び出し（エッジでの軽量推論モデルおよびクラウドの大規模モデル）の抽象化、ルーティング、キャッシュ、トークン制御を担うAPIゲートウェイを構築します。
  - **分離実行環境**  
    エッジ側ノード（ソノブイ／ローカル親局）とクラウド側（統合解析基盤）を完全にコンテナ分離し、通信帯域制約下でも独立して動作可能な設計とします。

## **エッジ側とクラウド側の処理分担**

| 区分 | 担当機能・役割 | 主な処理内容・要素技術 |
| :-: | :-: | :-: |
| **エッジ側（ソノブイ・哨戒機機内ノード）** | リアルタイムSignal処理・INSドリフト補正計算 | ・RTL-SDRによるHF地表波の受信・位相解析・TDOA用タイムスタンプ付与・自律EKFによるINS位置補正・データ圧縮 |
| **クラウド/親局側（統合ネットワーク解析基盤）** | ソノブイネットワーク全体の位置統合最適化・LLM解析 | ・ソノブイ群の分散型TDOA/EKF統合位置推定・Dubinsパスを用いた効率的旋回・補正飛行計画・LiteLLMを経由した状況解析 |

# **3. シミュレータの機能要件**

シミュレータは、海洋環境における動体力学および電波伝搬の物理的制約を正確に再現する必要があります。

## **Dubinsパス（Dubins Path）生成機能**

  - **要件**  
    対潜戦（ASW）で用いられる追尾用（対潜用）ソノブイと、位置補正用（代替PNT用）のGサイズソノブイを「完全に別々のノード」として定義・管理すること。シミュレータ上では、哨戒機（MPA）が対潜用ソノブイの敷設任務を実行すると同時に、位置補正専用のGサイズRFブイ（5〜9本程度）で構成されるPNTグリッドを別途展開・配置し、自機の位置補正（INSバウンディング）を行う最適な旋回飛行・展開経路（LSC, RSR等）を算出・評価するアルゴリズムを実装すること。
  - **目的**  
    GPS拒否環境下において、対潜用ソノブイとは独立した位置補正専用のGサイズRFブイ網を独立したローカルDGPS基準点として展開・運用することで、対潜哨戒作戦と自機位置の高精度な維持（代替PNT）を明確に分離・並列処理するキャリブレーション飛行計画の策定および評価を行うこと。

## **TDOA / EKF 位置補正（INSバウンディング）エンジン**

  - **TDOA（Time Difference of Arrival）/ Carrier Phase 位置補正および逆TDOA（Rx-TDOA）処理フロー**  
    既知の位置にある複数の友軍HF送信局（アンカーノード）からのパイロットトーン付きOFDM（帯域幅3kHz〜6kHz）信号を利用し、信号到達時間差（TDOA）およびパイロット信号を位相基準としたCarrier Phaseトラッキング（搬送波位相測位）を行うことで、海面漂流ソノブイ群および哨戒機（母機）の位置を高精度に特定・補正します。本機能では、未知の発信源の位置を特定する一般的なTDOAとは異なり、送信位置が既知である複数のアンカー拠点からの送信波を海面ソノブイ群および哨戒機（受信側）で受信し、その到達時間差（Rx-TDOA）から受信側ネットワーク全体の絶対座標を確定する「逆TDOA」の数理モデルと処理フローを評価・実装します。あわせて、これらアンカー拠点を基準とした幾何学的精度低下率（GDOP）の最適化を含む交差計算を実装要件とします。
  - **EKF（Extended Kalman Filter）による INS バウンディング**  
    HF地表波によって絶対座標が決定された海面ソノブイ群のダイバーシティ受信データや位相・伝搬遅延情報と、母機（哨戒機）の機内INS（慣性航法装置）出力を融合（センサ統合）し、航空機自身の時間経過に伴う累積ドリフト誤差を継続的にバウンディング（抑制）します。（高価なINSを搭載しないソノブイ自身の絶対座標はHF波により確定し、それを基準点として母機のINS補正に利用します。）

## **VHF / UHF 通信制約の再現**

  - **近距離通信（ソノブイ ⇔ 中継局）**  
    VHF/UHF帯を用いた局所データリンクを想定（VHFリンクの帯域上限は120kbps）。エッジ（DDC：デジタルダウンコンバータ）処理により、受信したパイロットトーン付きOFDM信号（帯域幅3kHz〜6kHz）を抽出・間引くことで120kbpsの帯域制約内に収めて伝送します。
  - **物理制約モデル**  
    海面反射（Two-Ray Ground Reflectionモデル）、波浪によるアンテナ傾斜・シャドウィング損失、フリスの伝送公式に基づくPath LossおよびBER（ビットエラーレート）の動的変動をシミュレートする機能を備えます。

## **引き継ぎにあたっての注意事項（Claude向け）**

1.  コードを生成・修正する際は、エッジ側の低リソース環境およびリアルタイム慣性補正を考慮し、数値計算（TDOA/EKF/Dubins）には numpy / scipy を用いたベクトル化処理を徹底してください。
2.  LiteLLM設定ファイル（config.yaml）は、将来的なローカルLLM（Ollama等）とクラウドLLM（Claude/GPT）の切り替えが容易な構成を維持してください。

# **6. PoC（概念実証）の実施ステップ**

リスクとコストを最小限に抑えつつ検証を進めるため、以下の4つのフェーズに従って開発・評価を実施します。

  - **フェーズ1：ローカル環境での代替PNTシミュレーション**  
    Apple Silicon Mac上でのLiteLLM Proxyを用いたエッジ/クラウドのハイブリッド推論ルーティング検証、およびINSドリフト補正用EKFモデルの統合
  - **フェーズ2：実RFデータを用いたHIL（Hardware-in-the-Loop）検証**  
    RTL-SDR V4による実環境ノイズを含むHF帯信号のサンプリングと、DDCによる帯域抽出・圧縮処理のソフトウェア検証
  - **フェーズ3：通信ボトルネックの物理エミュレーション**  
    FTDI USB-シリアル変換ケーブル等を利用し、シリアル通信の転送レートを120kbps（またはボーレート115200bps等）に制限することで、VHFリンクの極小帯域幅を物理的に模倣してデータフローを実証
  - **フェーズ4：沿岸部での小規模フィールドテスト**  
    数十キロ間隔で配置したSDR受信機群による固定静的アレイの構築と、船舶・航空機からのHF地表波を用いた代替PNTおよびINSバウンディングの実証
